About

OpenMedsDB is a personal project built and maintained by Sanket Patil — a free, searchable reference for medicine composition, uses, side effects, dosage, interactions and safety advice.

Who built this

I'm Sanket Patil, a software engineer based in Pune, India, working at Plus91 Technologies. I spend most of my time on backend and systems programming — primarily in Go and Rust — building things like storage engines, caching proxies and other performance-sensitive infrastructure. I'm an open-source enthusiast, and I enjoy taking something complicated and making it simple to use.

OpenMedsDB came out of that same instinct. Reliable drug information exists, but it's scattered across package inserts, drug indexes and clinical references that aren't especially easy to search or cross-check. This site pulls that information into one clean, fast, no-login interface — including a drug interaction checker that cross-references each medicine's listed interactions against the active salts of everything else you add.

GoRustPythonJavaScriptPostgreSQLRedisLinux

How it works

  • The medicine database is published as an open dataset on Hugging Face and read directly by this static site — there is no backend server.
  • Records are bundled and indexed for fast client-side search by brand name, salt, manufacturer and therapeutic class.
  • The interaction checker matches each medicine's documented interactions against the salt composition of the other medicines you select, then ranks findings by severity.
